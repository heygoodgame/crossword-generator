# Initial classification evaluation — 2026-09-18

Jev is worth further testing for content-angle screening and semantic comparisons
between clues/hints. These runs do **not** support replacing the generator's
general grader or making automatic repair decisions from the current questions.
Grammar and current-state checks need more work. Production behavior is unchanged.

## What was run

- Jev `jev-1.13.0`: 500 preserved historical clues against ten applicable questions
  from `editorial-v1`; another three questions require hint/prior-clue data that
  the historical corpus does not contain.
- Jev: 68 authored controls, three repeats each, covering all 13 questions.
- Claude `claude-sonnet-5`: the same 68 controls and questions, one repeat.
  67 valid responses; one invalid response. A separately preserved retry succeeded.
- State ablation: Jev evaluated four unchanged content/current-state questions
  with **only the clue**, on the 500 historical clues and 68 controls, once each.
- 85 historical states were separately agent-reviewed before the historical run;
  their predictions were rescored without further inference.

The 500 original grader verdicts remain **unverified reference data**, not labels.
The 85-case review is selected and mostly negative; the controls were written
alongside the questions. Neither is independent human gold. Most questions have
only 4–8 labeled controls, so perfect scores below are diagnostic, not deployment
accuracy estimates. All decisions here use an exploratory threshold of 0.5;
Jev repeats are averaged per case. No threshold was tuned for production.

*Claude's GO / “Departed” request failed validation. Its separate retry returned

not silently folded into the paired comparison. That original failure occurred
before invalid-output preservation was added, so its raw output is unavailable.

Jev's tense positives were 0.327–0.480. Its AUC on these six controls is 1.0 despite
zero recall at 0.5: the ranking contains signal, but the operating threshold is
unsuitable. Choosing a lower threshold from these same six cases would overfit.
This is also why matching a 0.5 threshold across models is not calibration.

## Historical observations

Across all 500 cases, Jev flagged 24 current-state risks, 0 number mismatches,
2 tense mismatches, 39 part-of-speech mismatches, 4 firearms angles, 9 alcohol
angles, 0 drug angles, 222 plain definitions, 56 specialist clues, and 10 unnatural
clues. These are flag counts, not measured defects.

Within the 85 reviewed cases:

- Current-state: caught both labeled positives, but falsely flagged YOURS /
  “Belonging to you” (0.74), THEIR / “___ house is blue” (0.63), and RENEW /
  “Keep a subscription going” (0.58). False-positive rate: 3/83.
- Part of speech: 10 false positives among 85 negatives. Examples include EASE /
  “Make less painful” (0.61) and AGE / “Mature gracefully, like fine wine” (0.68).
- Plain definition: 59/78 agreement (75.6%), with subjective labels. Treat this
  as a ranking/editorial signal, not an automatic defect.
- Number and tense: no labeled positives, so apparent perfect accuracy says
  nothing about recall. Firearms and drugs likewise have no reviewed positives.
  AMMO/slingshot and FLASK cases were left unlabeled for the ambiguous categories.

## State ablation: useful tradeoffs, not a universal fix

The clue-only suite reuses the exact four instructions and excludes `answer`.
It also has fewer questions per request, so this is an exploratory comparison,
not an isolated causal test of the answer field alone.

| Historical pair | Alcohol, answer + clue | Alcohol, clue only |
|---|---:|---:|
| BEER / “Ginger ___” | 0.71 | 0.17 |
| BEERS / “Root, A&W, and Mug, all named for one” | 0.85 | 0.11 |
| BEER / “Root ___ float (ice cream treat)” | 0.31 | 0.10 |
| AGE / “Mature gracefully, like fine wine” | 0.90 | 0.94 |

This is consistent with answer associations influencing the content judgment,
but does not establish how Jev works internally. Some blanks require the answer:
STAR / “Shooting ___” became a firearms false positive (0.57) with clue-only state.
The six alcohol controls still passed; firearms dropped from 6/6 to 5/6.

Current-state became worse: reviewed false positives rose from 3/83 to 11/83,
while both positive historical cases were still caught. RENEW / “Keep a
subscription going” rose to 0.73. Merely removing the answer does not fix that rubric.

## Recommended next uses

1. **Content-angle triage:** extend nonalcoholic, figurative, and fill-in-the-blank
   boundary cases. Keep answer context available when it resolves the clue, and
   evaluate a separate clue-only signal rather than globally dropping the answer.
2. **Semantic duplicate clues and hint usefulness:** collect actual candidate/old
   clue and clue/hint pairs. These matched Jev's strengths in the small controls,
   but historical validation is still missing.
3. **Editorial ranking:** test plain-definition and specialist-knowledge signals
   against independent editor judgments before using them to reject candidates.
4. **Grammar/current-state:** keep as experiments. Add concrete negative criteria
   for ownership pronouns, subscriptions, and other ordinary relationships to the
   current-state question. Evaluate grammar thresholds on a larger development set
   and then freeze them for a separate test set.

Literal containment remains better handled by deterministic code. The preserved
legacy leak prompt/corpus can now be run through this same framework, but the
lost morpheme-label builder has not been re-created or claimed as a verified oracle.
